# Включение в Единый реестр российского ПО

Цель — соответствие требованиям для внесения China-RU в реестр отечественного ПО
(ПП РФ № 1236). Заметка фиксирует, что нужно соблюдать по ходу разработки, чтобы к
моменту подачи не переделывать.

## Что важно обеспечить заранее

1. **Исключительные права.** Весь код — собственная разработка; вклады оформляются так,
   чтобы права принадлежали правообладателю (договоры/трудовые отношения). Сторонние
   компоненты — только под свободными лицензиями (MIT/Apache‑2.0/BSD/ISC и совместимые),
   без проприетарных зависимостей и без обязательных платежей иностранным лицам.
2. **Происхождение.** Управление и разработка не контролируются иностранным лицом
   (организационное требование, вне кода).
3. **Документация на русском языке:** описание функциональных характеристик, руководство
   по установке (экземпляр для проверки) и руководство пользователя/администратора.
4. **Самостоятельное развёртывание.** Сборка и запуск из исходников на инфраструктуре
   заказчика (Docker Compose), без привязки к зарубежным облакам как обязательному
   условию работы (внешние сервисы — опциональны/заменяемы).
5. **Лицензии зависимостей** — вести реестр (SBOM): автоматическая проверка лицензий в CI
   (добавляется в фазе R7), запрет копилефт‑несовместимых и проприетарных пакетов.

## Стек и импортозамещение

Базовый стек (Node, PostgreSQL, Redis, SeaweedFS, Next.js, React) — открытое ПО
под свободными лицензиями. Размещение — на российском VPS/облаке. PostgreSQL допускает
замену на Postgres Pro при необходимости.

## Где это отражается в репозитории

- `LICENSE` и заголовки правообладателя — фаза R7.
- `docs/` на русском: функциональные характеристики, установка, руководства — R7.
- Проверка лицензий зависимостей в CI (license‑checker / SBOM) — R7.
