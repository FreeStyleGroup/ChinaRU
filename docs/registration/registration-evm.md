## 3. Пакет для реестра ПО (следующий этап) + чем «зарубить» отказ

Killer-причины отказов 2025–2026 и как мы их закрываем:
1. 🔴 **Иностранный контроль функциональности** — ни одного хардкод-вызова иностранного сервиса,
   без которого ломается ключевая функция. Внешние API (если есть) — только серверные, опциональные,
   заменяемые. → уже в `docs/registry-po.md`.
2. 🔴 **Нет подтверждения исключительных прав** → договор отчуждения (наш) + указание авторов.
3. 🔴 **Расхождение в названии** → одинаковое имя везде.
Плюс к подаче: описание функциональных характеристик, руководство пользователя и по установке
(на русском), SBOM (реестр лицензий зависимостей, все свободные), самостоятельное развёртывание из
исходников (Docker Compose), хостинг в РФ, 152-ФЗ.
