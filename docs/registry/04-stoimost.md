## 1. Порядок предоставления

Программное обеспечение предоставляется правообладателем **безвозмездно**.

Плата за предоставление права использования программного обеспечения не
взимается, в том числе плата за установку, обновление, получение новых версий
и техническую поддержку в объёме, предусмотренном документом «Описание
процессов, обеспечивающих поддержание жизненного цикла программного
обеспечения».

Регистрация и работа пользователей на площадке — покупателей и продавцов —
осуществляются без взимания платы за доступ к программному обеспечению.

## 2. Источник финансирования разработки и развития

Разработка, развитие и сопровождение программного обеспечения финансируются
правообладателем за счёт собственных средств.

Доход правообладателя формируется за счёт комиссионного вознаграждения
за сделки, совершённые с использованием площадки, и размещения информационных
материалов. Указанное вознаграждение является платой за услуги, оказываемые
правообладателем участникам площадки, и **не является платой за предоставление
права использования программного обеспечения**. Размер комиссии определяется
условиями пользовательского соглашения и не влияет на возможность использования
программного обеспечения.

## 3. Услуги, оказываемые на возмездной основе

Правообладатель вправе оказывать на возмездной основе услуги, не связанные
с предоставлением права использования программного обеспечения:

| Услуга | Порядок определения стоимости |
|---|---|
| Развёртывание экземпляра на инфраструктуре заказчика | По фактическим трудозатратам |
| Доработка функциональности под требования заказчика | По согласованному техническому заданию |
| Обучение персонала заказчика | По количеству обучаемых |
| Расширенная техническая поддержка сверх базового объёма | По согласованному регламенту обслуживания |

Стоимость таких услуг определяется в отдельном договоре и не является условием
предоставления права использования программного обеспечения.

## 4. Отсутствие обязательных платежей иностранным лицам

Использование программного обеспечения не влечёт возникновения обязательств
по выплатам в пользу иностранных физических и юридических лиц. В составе
программного обеспечения отсутствуют проприетарные компоненты, требующие
лицензионных отчислений. Все используемые сторонние компоненты распространяются
на условиях свободных лицензий, не предусматривающих платежей правообладателям.

Функционирование программного обеспечения не требует приобретения услуг
иностранных поставщиков облачной инфраструктуры.
