## Дорожная карта воссоздания

Каждый раздел: публичная часть + отражение в кабинете + админ-управление.

1. **Кабинет покупателя — добить по исходникам/макетам:** Профиль (расширенный +
   Карты оплаты, Адрес доставки), Мои заказы (Избранное / Отзывы / Вопрос-Ответ /
   Баллы и Купоны), Социальная сеть (`china:feed`), Афиша (`china:events`),
   Путешествия (`china:travel`), Работа (`china:job`), Консьерж, Обучение
   (`china:school`), Гороскоп (`china:horoscope`), Акции.
2. **Кабинет продавца** (`/seller/my/`): Обзор/Товары/Заказы/Магазин/Аналитика/
   Продвижение/Помощь.
3. **Публичные вертикали:** Авто/Мото (+ Гараж, фитмент), Расходники и запчасти,
   Бренды, Магазины.
4. **Контент/сервисы:** Наши услуги, Полезное (Рецепты, Метро, Погода, Школа HSK,
   Гороскоп, Проверка контрагента), Новости/Публикации/Обзоры, Бизнес клуб.
5. **Сложные площадки (логику даёт заказчик):** Тендеры (`china:tenders`),
   Грузоперевозки (`china:cargo`).
6. **Реальная логика поверх демо:** кошелёк, рефералка, лояльность; поиск
   (Meilisearch), уведомления.
