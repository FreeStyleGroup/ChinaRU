# ADR 0007 — Закалка: i18n-контент, кеш, CSRF, observability, аудит

- **Статус:** принято
- **Дата:** 2026-06-12

## Контекст

После функциональных фаз (R3–R5) нужно довести проект до прод-готовности по
осям SEO/i18n, производительности, безопасности и наблюдаемости — не ломая
зелёные гейты и работу без внешних сервисов в тестах.

## Решение

1. **Локализация контента витрины.** Хелперы `localizedName` / `pickText`
   выбирают поле под локаль (`zh`→`nameZh`, `en`→`nameEn`, откат на `ru`).
   Применены в карточке, странице товара (заголовок, описание, `generateMetadata`,
   JSON-LD) и чипсах категорий — теперь на китайский/английский переключается и
   контент, а не только интерфейс.
2. **Кеш (Redis, опционально).** Интерфейс `Cache` + `RedisCache` (ioredis, JSON,
   ошибки кеша не валят запрос) и `NoopCache`. Контейнер выбирает реализацию по
   `REDIS_URL` (пусто → Noop). Дерево категорий кешируется (TTL из конфига). Тесты
   идут на NoopCache — без Redis.
3. **CSRF для cookie-сессий.** CORS больше не бросает 500 на чужой origin (просто не
   выставляет заголовки); `csrfGuard` на изменяющих методах отклоняет запросы с
   чужим `Origin` (браузер всегда его шлёт), пропуская запросы без Origin
   (сервер-сервер) и `Bearer` (мобильные, без амбиентных cookie).
4. **Observability.** `pino-http` логирует каждый запрос со структурой и request-id.
5. **Аудит.** `AuditRepository` + запись в `audit_log` при админских действиях
   (верификация продавца, модерация отзыва) с актором и IP.
6. **Расширенная микроразметка.** JSON-LD `Organization` на главной (в дополнение к
   `Product`/`BreadcrumbList` на карточке).

## Последствия

- API: 28 тестов (RBAC/CSRF/кеш/аудит), 18/18 гейтов зелёные, `next build` и
  `vite build` собираются. Прод-сервер API — 0 уязвимостей; известные 2 moderate —
  postcss внутри Next (build-time).
- Кеш и Redis включаются конфигом; без `REDIS_URL` всё работает на NoopCache.
- Осталось на R7: Docker dev+prod, CI-деплой, staging; глубже — полнотекстовый поиск
  (Meilisearch) и расширенная аналитика как отдельные инициативы.
