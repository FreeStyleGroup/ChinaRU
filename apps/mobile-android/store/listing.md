# Страница приложения в RuStore — черновик

Заполняется в консоли: **Приложения → ChinaRU → Страница приложения**.
Тексты ниже — под первую версию (каталог, поиск, заявка). Обещать в них
то, чего в сборке нет, нельзя: модерация сверяет описание со сборкой.

---

## Название

```
ChinaRU
```

## Краткое описание

```
Товары и оборудование из Китая: каталог, поиск, заявка поставщику
```

## Полное описание

```
ChinaRU — приложение сервиса chinaru.ru для тех, кто закупает товары
и оборудование в Китае.

Что внутри:

• Каталог — категории и карточки товаров с характеристиками и фотографиями.
• Поиск по каталогу — по названию и характеристикам, с сохранением
  последних запросов.
• Заявка — отправить запрос на подбор и расчёт стоимости прямо из карточки
  товара, не переходя на сайт.

Приложение работает без регистрации. Личный кабинет, оплата и отслеживание
заказов появятся в следующих версиях.

Сервис chinaru.ru работает с 2016 года: подбор поставщиков, проверка
контрагентов, доставка и таможенное оформление.
```

> Последний абзац проверить по фактам перед публикацией: год и перечень
> услуг должны совпадать с тем, что написано на сайте. Расхождение —
> повод для отказа.

## Категория

`Покупки` (проверить точный список категорий в консоли).

## Возрастной рейтинг

`0+` — при условии, что в приложении нет пользовательского контента,
чата и внешних ссылок на сторонние площадки. Появится ИИ-консультант с
пользовательским вводом — рейтинг придётся пересмотреть.

## Графика

| Материал | Требование | Статус |
|---|---|---|
| Иконка | 512×512 PNG | ✅ `store/icon-512.png` |
| Скриншоты телефона | от 3 штук, реальные экраны сборки | ❌ нет |

Скриншоты снимаются с работающего приложения. Рисованные макеты и экраны
с несуществующими функциями — прямое основание для отказа, поэтому они
появятся только после подключения каталога к данным.
