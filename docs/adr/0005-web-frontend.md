# ADR 0005 — Витрина: Next.js 15, i18n, дизайн-система, SEO

- **Статус:** принято
- **Дата:** 2026-06-12

## Контекст

Нужна публичная витрина инвест-уровня: SEO-дружественная (каталог на 10k+ страниц),
многоязычная (ru/en/zh), с переиспользуемой дизайн-системой и типобезопасным
доступом к API (R3).

## Решение

1. **Next.js 15 App Router (SSR/ISR).** Каталог и карточки рендерятся на сервере с
   ревалидацией (`fetch … next.revalidate`), что даёт и SEO, и кеш. Карточка товара —
   динамический рендер по запросу.
2. **i18n — next-intl с локале-префиксом** (`/[locale]/…`). Список локалей берётся из
   `@china-ru/shared` (единый источник). Сообщения — `messages/{ru,en,zh}.json`.
   Middleware определяет локаль, `setRequestLocale` включает статический рендер.
3. **Дизайн-система — `packages/ui`** на Tailwind v4 + cva: `cn`, `Button`, `Container`,
   `Card`, `Badge`. Токены бренда заданы в `@theme` (фирменный красный + сланцевые
   нейтрали + золотой акцент) и переиспользуются витриной и (позже) админкой.
4. **Доступ к API — два тонких клиента:** серверный (`lib/api.ts`, ISR-кеш, каталог) и
   браузерный (`lib/api-client.ts`, `credentials: include` для httpOnly-сессий, auth и
   заказы). Оба разбирают конверт `ApiResponse` и бросают типизированную ошибку.
5. **SEO по умолчанию:** `generateMetadata` (canonical + Open Graph) на каждой странице,
   JSON-LD Schema.org (`Product`, `BreadcrumbList`), динамические `sitemap.xml` и
   `robots.txt`.
6. **Авторизация на клиенте** — `AuthProvider`/`useAuth` поверх браузерного клиента
   (восстановление сессии через `/auth/me`, login/register/logout).
7. **Устойчивость:** server-fetch обёрнут в try/catch — недоступность API не валит
   сборку и отдаёт пустое состояние вместо ошибки.

## Последствия

- `next build` зелёный: 17 страниц, локали ru/en/zh, карточка товара — on-demand.
- Тесты витрины — чистые функции (SEO/JSON-LD, форматирование) на Vitest; визуальный QA
  планируется через Playwright MCP.
- Добавление страницы = серверный фетч из `lib/api` + `generateMetadata` + компоненты из
  `@china-ru/ui`, по зафиксированному шаблону.
