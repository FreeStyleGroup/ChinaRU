# China.ru — карта сайта и дорожная карта воссоздания

> Цель: полностью воссоздать текущий сайт с Битрикс (china-ru.ru) на нашей
> современной платформе (Next.js + Node + PostgreSQL) — безопасно и красиво, затем
> дополнять. Здесь — карта разделов и порядок работ. Кабинет детализирован в
> [cabinet-sections.md](./cabinet-sections.md).
>
> Источник: главное меню и раздел «Авто» сняты с живого сайта; кабинет — со
> скриншотов заказчика. Внутренности остальных публичных разделов уточняем точечно
> перед сборкой каждого (живой Битрикс отвечает медленно/не по очевидным слугам).

## Верхняя навигация (публичная часть)

1. **Авто/Мото** — каталог авто/мото/спецтехники + запчасти.
2. **Расходники и запчасти** — каталог расходников/запчастей.
3. **Наши услуги** ▾ — 9 подпунктов (уточнить состав).
4. **Тендеры** — площадка тендеров (логику даёт заказчик; сложный раздел).
5. **Грузоперевозки** — биржа грузоперевозок (логику даёт заказчик; сложный раздел).
6. **Бизнес клуб** — (уточнить).
7. **Путешествия** — авиабилеты/отели/туры/бизнес-тур/авто/страховки (см. кабинет).
8. **Полезное** ▾ — 8 подпунктов (контент/справка/блог — уточнить).
9. **Работа** — вакансии/резюме (в кабинете: «Моё резюме» + отклики).

Шапка: логотип China.ru, кнопка «Каталог», поиск (по артикулу/наименованию/VIN),
выбор региона (Москва, СПб, Екатеринбург, Новосибирск, Владивосток), язык, вход/кабинет.

## Раздел «Авто» (снят с живого сайта)

- **Категории техники:** Спецтехника (экскаваторы, погрузчики, самосвалы),
  Мототехника (мотоциклы, скутеры, квадроциклы).
- **Популярные марки (16):** Haval, Chery, Geely, Changan, Exeed, Omoda, Jaecoo,
  TANK, Jetour, Great Wall, Lifan, Brilliance, Zotye, Belgee, Soueast, Tenet.
- **Поиск/фильтры:** по артикулу / наименованию / VIN; фильтр по городам.
- **Каталог мототехники:** мотоциклы, мопеды/скутеры, питбайки, трициклы,
  мотобуксировщики, снегоходы, квадроциклы.
- **Промо:** новые поступления, сезонная распродажа, горячие предложения.
- Связка с кабинетом: «Мой гараж» (см. cabinet-sections.md).

## Личный кабинет (детально — в cabinet-sections.md)

Закреплённые: Профиль (+ Карты оплаты, Адрес доставки) · Мои заказы (+ Избранное,
Мои отзывы, Вопрос/Ответ, Баллы и Купоны) · Социальная сеть · Кошелёк · Мои
партнёры · Мой магазин (кабинет продавца) · Путешествия · Мой гараж.
Опциональные (тумблеры): Консьерж · Афиша · Тендеры · Грузоперевозки · Работа ·
Обучение · Гороскоп · Акции.

## Что уже воссоздано на нашей платформе

- Витрина-каркас: главная, каталог (листинг+фильтры+пагинация), карточка товара

- Кабинет: каркас (сайдбар+меню с кастомизацией), Профиль (базовый), Мои заказы,

- Бэкенд: каталог, заказы, авторизация, account, админка; БД/контракты/безопасность.

## Дорожная карта воссоздания (порядок — уточняется с заказчиком)

Каждый раздел: публичная часть + отражение в кабинете + админ-управление, на единых
паттернах (Zod-контракты → репозитории → API → SSR-страницы), демо-данные там, где
логика ещё обсуждается.

1. **Кабинет покупателя — добить экраны по макетам:** Профиль (расширенный: фамилия,
   дата рождения, аватар, смена пароля, Карты оплаты, Адрес доставки), Мои заказы
   (Избранное / Мои отзывы / Вопрос-Ответ / Баллы и Купоны), Афиша, Путешествия,
   Работа, Социальная сеть, Консьерж, Обучение, Гороскоп, Акции.
2. **Кабинет продавца («Мой магазин»):** табы Обзор/Товары/Заказы/Магазин/Аналитика/
   Продвижение/Помощь.
3. **Публичные вертикали каталога:** Авто/Мото (+ Гараж), Расходники и запчасти.
4. **Контент-разделы:** Наши услуги, Полезное, Бизнес клуб.
5. **Сложные площадки (логику даёт заказчик):** Тендеры, Грузоперевозки.
6. **Доработки:** реальная логика поверх демо-экранов (кошелёк, рефералка, лояльность),
   поиск (Meilisearch), уведомления.

> Чат покупатель↔продавец — отложен (не делаем сейчас).
