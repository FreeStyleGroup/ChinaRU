## Что вписать правообладателю (единый список)

Во все три подписываемых документа (договор + 2 согласия) — **одни и те же** данные автора:
- дата и место рождения;
- паспорт: серия, номер, кем и когда выдан, код подразделения;
- адрес регистрации;
- (в договоре) сумма вознаграждения и порядок выплаты — можно символическую.

Плюс для заявления (см. `zayavlenie-fields.md`):
- решение по публикации автора (ФИО или «не публиковать»);
- email для переписки с ФИПС;
- дата первого опубликования (если была; иначе пусто);
- подтвердить формулировку графы ПДн «не содержит».

## Пересборка генерируемых материалов
```
node docs/registration/build-listing.mjs   # → out/listing.html → PDF (печать из браузера)
node docs/registration/build-sbom.mjs       # → out/SBOM.md
```
Папка `out/` — в `.gitignore` (артефакты сборки). Скрипты и шаблоны — под контролем версий.

## Порядок подачи (Этап 1)
1. Вписать паспортные данные в договор + 2 согласия, подписать.
2. Войти в ЛК ФИПС (new.fips.ru), начать заявление на ПрЭВМ.
3. Заполнить графы по `zayavlenie-fields.md`.
4. Прикрепить: листинг (депон. материалы), реферат, договор, 2 согласия.
5. Рассчитать пошлину в калькуляторе ФИПС (юрлицо ~4 500 ₽, **−30 % при эл. подаче**), оплатить от ООО, приложить квитанцию.
6. Подписать УКЭП ООО, отправить. Свидетельство — ~2 мес.
