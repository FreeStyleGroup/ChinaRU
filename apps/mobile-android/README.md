# ChinaRU — Android

Нативное приложение на Kotlin + Jetpack Compose. Публикация — RuStore
(приложение в консоли уже заведено под именем **ChinaRU**).

## Состояние

Каркас собирается и запускается. Данные пока **выдуманные**: `HomeViewModel`
и остальные ViewModel возвращают мок-список после `delay(1500)`. Сетевого слоя
нет — он появится, когда будет готов Mobile BFF в `apps/api`.

Экраны: Главная (поиск, категории, сетка товаров), Каталог, Корзина, Профиль,
карточка товара. Нижняя навигация — 4 вкладки.

## Требования

| | |
|---|---|
| JDK | 21 (подходит тот, что внутри Android Studio: `.../Android Studio/jbr`) |
| Android SDK | platform 37, build-tools 36+ |
| Gradle | 9.5 (ставится обёрткой `gradlew` сам) |
| AGP | 9.3.2 — Kotlin в нём встроенный, отдельный плагин `kotlin-android` подключать нельзя |

`local.properties` в репозиторий не входит; путь к SDK пишется через прямые
слэши, иначе Gradle падает с `Invalid file path`:

```properties
sdk.dir=C:/Users/<вы>/AppData/Local/Android/Sdk
```

## Сборка

```bash
export JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"

./gradlew :app:assembleDebug     # APK для установки на устройство
./gradlew :app:bundleRelease     # AAB для загрузки в RuStore
```

Артефакты: `app/build/outputs/apk/debug/app-debug.apk` и
`app/build/outputs/bundle/release/app-release.aab`.

## Подпись

**RuStore не хранит и не выдаёт ключи разработчика.** Потерянный ключ означает,
что обновить приложение уже нельзя — только выпускать новое, с другим именем
пакета и с нуля набранной аудиторией. Ключ и пароли к нему храните там же, где
остальные боевые секреты.

Создать ключ (один раз, срок — 30 лет, меньше ставить незачем):

```bash
"/c/Program Files/Android/Android Studio/jbr/bin/keytool" -genkeypair \
  -v -keystore chinaru-release.jks \
  -alias chinaru -keyalg RSA -keysize 4096 -validity 10950
```

Затем скопировать `keystore.properties.example` в `keystore.properties`
и заполнить. Пока файла нет, `bundleRelease` собирает **неподписанный** AAB —
консоль RuStore такой не примет. Это сделано намеренно: release, подписанный
отладочным ключом, выглядит рабочим ровно до попытки его загрузить.

## Что важно не сломать

- **`applicationId = "com.chinaru.app"`.** После первой публикации имя пакета
  не меняется: RuStore опознаёт приложение именно по нему. Перед первой
  загрузкой убедитесь, что в консоли приложение заведено на это же имя.
- **`versionCode`** обязан расти с каждой загрузкой. Одинаковый код — отказ
  при загрузке.
- **`minSdk = 26`** — из-за адаптивной иконки. Ниже понадобится растровый
  набор `mipmap-*dpi`.

## Требования RuStore к сборке

- APK или AAB; AAB предпочтителен — на устройстве приложение занимает меньше.
- Подпись обязательна, ключ ваш.
- `targetSdk` не ниже 28 (у нас 37), поддержка 64 бит.
- Альфа- и бета-тестирование доступны после того, как в каталоге появилась
  первая опубликованная версия.
