## 4. Порядок действий

1. Вписать паспортные данные в три документа, подписать.
2. Войти в ЛК ФИПС с УКЭП ООО, начать заявление на регистрацию программы для ЭВМ.
3. Заполнить графы по `zayavlenie-fields.md`.
4. Прикрепить листинг, реферат, договор, два согласия.
5. Рассчитать и оплатить пошлину от ООО, приложить квитанцию.
6. Подписать УКЭП, отправить. Свидетельство — около двух месяцев.

3. Подать заявление через ЕПГУ с УКЭП ООО.
